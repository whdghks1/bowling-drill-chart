# Bowling Drill Chart · Fit Studio

볼러별 지공차트, 볼 미리보기, A4 지공 작업표를 제공하는 Netlify + Neon 웹앱입니다.

- 관리자: 차트 등록·수정, 클럽 공개 여부 지정, 인쇄/PDF 저장
- 방문자: 로그인 없이 **공개 설정된 차트만 읽기 전용 조회**
- 로그아웃 상태: 공개 차트 조회 가능, 저장 불가
- 스팬, 브리지, 홀 규격, 피치, 인서트, 엄지 타원, PAP 및 레이아웃 기록
- `4 3/8`, `7/8`, `1/64` 및 소수 치수 입력. 빈칸과 0을 구분

## 1. Netlify에 연결

Netlify에서 **Add new project → Import an existing project → GitHub**를 선택하고 이 저장소를 연결합니다. Netlify GitHub 앱이 이 저장소에 접근할 수 있어야 합니다.

`netlify.toml`에 다음 설정이 포함되어 있습니다.

| 항목 | 값 |
| --- | --- |
| Build command | `npm run build` |
| Publish directory | `dist` |
| Functions directory | `netlify/functions` |
| Node.js | 22 |

## 2. 기존 Neon DB 연결 및 테이블 준비

새 DB를 자동 생성하지 않습니다. 이미 사용하는 Neon 프로젝트의 연결 주소를 사용하세요.

Netlify에 기존 Neon extension이 연결되어 있고 **`NETLIFY_DATABASE_URL`**이 제공된다면 그대로 사용합니다. 그렇지 않으면 Neon의 **Connect**에서 연결 문자열을 확인해 Netlify 환경변수 **`DATABASE_URL`**로 설정하세요. 두 값이 모두 있으면 `DATABASE_URL`이 우선합니다. DB 주소는 서버에서만 읽고 브라우저에 전달하지 않습니다.

Neon의 SQL Editor에서 [`sql/001-bowling-fit.sql`](sql/001-bowling-fit.sql)을 실행하고, 회원 기능에는 [`sql/002-members.sql`](sql/002-members.sql)도 실행하세요. 차트 테이블을 추가하며 기존 다른 서비스의 테이블은 수정하지 않습니다. 같은 SQL을 다시 실행해도 기존 차트는 삭제되지 않습니다.

또는 로컬 `.env`에 연결 문자열을 설정한 후:

```bash
npm ci
npm run db:setup
```

기존 ChatGPT Sites의 저장 데이터는 별도 DB에 있으므로 이 코드 업로드만으로 Neon으로 이전되지 않습니다. 이 저장소에는 실제 회원 데이터나 DB 비밀번호가 포함되지 않습니다.

## 3. Netlify 환경변수 설정

프로젝트의 **Environment variables**에서 다음 값을 설정합니다. 범위를 선택할 수 있다면 **Functions**를 포함하세요. 값에 `VITE_` 접두사를 붙이지 마세요.

| 변수 | 설정 |
| --- | --- |
| `DATABASE_URL` 또는 `NETLIFY_DATABASE_URL` | 기존 Neon 연결 주소. 연동으로 이미 제공되면 중복 입력 불필요 |
| `ADMIN_PASSWORD` | 최초 관리자 계정 등록 확인용 기존 비밀번호. 최소 12자 |
| `SESSION_SECRET` | 무작위 문자열. 최소 32자 |

세션 비밀키는 본인 컴퓨터에서 아래 명령으로 만들 수 있습니다.

```bash
node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
```

비밀번호·연결 문자열·세션 비밀키를 GitHub 파일, 이슈, 채팅에 올리지 마세요. 설정 후 Netlify에서 재배포하세요. 관리자 설정이 누락되면 관리자 로그인은 차단됩니다. 공개 조회에도 DB 연결 설정은 필요합니다.

## 4. 회원가입과 권한 관리

공개 차트는 누구나 로그인 없이 조회할 수 있습니다. 로그인 화면에서 이름·비밀번호로 가입하면 일반 회원이 됩니다. 이름은 2~40자이며 공백과 대소문자, 유니코드 호환 문자를 정규화해서 중복을 검사합니다. 새 비밀번호는 숫자 4자리이며 scrypt(개별 무작위 salt) 해시로 저장합니다. 기존 긴 비밀번호도 로그인과 현재 비밀번호 확인에 사용할 수 있으며, 계정 관리에서 숫자 4자리로 변경할 수 있습니다.

처음 한 번 **로그인 / 회원가입 → 기존 관리자 · 첫 계정 등록**을 선택하세요. 사용할 이름·새 비밀번호와 기존 `ADMIN_PASSWORD`를 입력하면 최초 관리자 계정이 만들어집니다. 기존 차트는 그대로 유지됩니다. 일반 회원가입이 최초 관리자 권한을 부여하지 않습니다. 등록 후에는 이름·비밀번호로 로그인하며 `ADMIN_PASSWORD`를 통한 추가 관리자 등록은 차단됩니다.

| 권한 | 할 수 있는 작업 |
| --- | --- |
| 비회원 | 공개 차트 조회·인쇄 |
| 일반 회원 | 공개 차트 조회·인쇄, 본인 비밀번호 변경 |
| 편집자 | 모든 차트 조회·등록·수정·공개 여부 변경 |
| 관리자 | 편집자 기능 + 회원 권한 변경·계정 정지/활성화 |

관리자는 **계정 관리 → 회원 관리**에서 회원별 권한·활성 상태를 선택하고 **적용**을 누릅니다. 자신의 권한·상태 변경은 차단됩니다. 회원 변경은 DB에서 직렬화하고 실행 시 관리자 권한을 다시 검사하므로 동시 요청으로 관리자가 전부 강등되는 것을 방지합니다.

권한·계정 상태·비밀번호 변경은 세션 버전을 갱신하고 다음 요청부터 기존 세션을 무효화합니다. 세션 쿠키는 HttpOnly/SameSite=Strict/Secure(HTTPS), 12시간 만료이며 권한은 매 요청마다 DB에서 확인합니다. 로그인·가입·최초 관리자 등록·비밀번호 변경은 DB 기반 시도 제한을 적용합니다. 회원 목록과 API 응답에 비밀번호 해시는 포함하지 않습니다.

차트 작성 시 **누구나 이 차트 조회 가능**을 체크하고 저장한 차트만 공개됩니다. 이름과 작업 메모를 포함한 전체 작업표가 공개됩니다. 정지된 회원도 비회원과 동일하게 공개 차트는 조회할 수 있습니다.

이메일·이름 실명 확인, 자동 비밀번호 찾기는 제공하지 않습니다. 비밀번호를 잊은 경우 운영자가 본인 확인 후 별도로 복구해야 합니다.

## 작업표의 범위

Jayhawk 프로숍 차트 항목을 참고한 **수치 작업표**입니다. 그림은 축척 없는 위치도이고 1:1 가공 템플릿이나 지공기 X/Y 좌표를 생성하지 않습니다. 작업표의 수치를 실측값·사용 게이지·지공기 기준과 대조해 사용하세요.

- [Jayhawk 차트](https://www.jayhawkbowling.com/Pro_s_Corner/Pro_Shop_Forms/balllayout.jpg.pdf)
- [Edge Gauge 측정 안내](https://www.jayhawkbowling.com/Pro_Shop_Manuals/jpegmanual.pdf)

## 작업표 바로 수정

편집자·관리자는 수치 작업표 안에서 이름, 스팬, 브리지, 홀 규격, 피치와 메모를 직접 수정할 수 있습니다. 변경 사항은 ‘작업표 저장’으로 저장하며, 기존 항목별 입력은 작업표 아래에서 펼칠 수 있습니다. 공개 조회와 인쇄에는 입력 컨트롤이 표시되지 않습니다.

## 모바일 · 펜슬 사용

- 편집 화면 상단에서 **수치 입력 / 자유 필기**를 전환합니다. 모바일에서는 **차트 선택**으로 볼러 목록을 열 수 있습니다.
- 자유 필기는 **필기 작업표 / 볼 그림** 두 페이지에 기록합니다. 펜 색상·굵기, 획 지우개, 실행 취소·다시 실행을 지원합니다.
- 기본은 펜슬·마우스 필기입니다. 손가락은 화면 이동에 사용하며, **손가락 필기**를 켜면 터치로도 그릴 수 있습니다. 실제 기기별 펜슬·팜 리젝션은 별도 확인이 필요합니다.
- **작업표 저장**을 눌러 수치와 필기를 함께 저장합니다. 필기 좌표는 기존 Neon 차트 JSON에 보관되므로 추가 DB 마이그레이션은 없습니다.
- 공개된 차트의 필기는 누구나 볼 수 있고, 수정은 기존 편집자·관리자 권한이 필요합니다. 인쇄/PDF에는 필기가 있는 페이지가 추가됩니다.
- 필기는 수치로 자동 인식되지 않습니다. 볼 그림은 직접 위치를 표시하는 축척 없는 참고도입니다. 수치 입력칸의 OS 손글씨 인식은 기기 설정에 따릅니다.

## 간소화된 항목과 한글 입력

- 홀 깊이·베벨 입력/표시 항목을 제거했습니다. 기존 저장값은 호환성을 위해 데이터 안에 유지합니다.
- 그립은 원핸드(엄지 사용), 덤리스, 투핸드, 컨벤셔널을 구분합니다. 기존 ‘엄지 없음’ 기록도 그대로 열립니다. 덤리스·투핸드는 엄지 홀과 스팬 항목을 표시하지 않습니다.
- 인서트 종류는 GNS, 없음, 직접 입력 중 선택합니다.
- 수치 입력칸에 ‘기존과 동일’, ‘조금 넓게’ 같은 한글을 입력할 수 있습니다. 한글이 포함된 값은 120자 이내 문구로 저장하고 조회/인쇄에 그대로 표시합니다. 숫자·분수는 기존 범위 검증을 적용합니다.
- 한글 문구는 수치로 변환하거나 도식 계산에 사용하지 않습니다. 치수가 없는 볼 미리보기는 기존처럼 참고용 예시 위치를 사용합니다.

# 3D 실험실 `/test`

기존 `/` 차트와 별도 경로에서 브랜드 → 제품 → 무게를 선택합니다. C³, Capacitor, Surge(Storm) 및 Hustle(Roto Grip)의 15 lb를 각각 별도 추정 형상으로 연결합니다. 제품의 실제 coreKey가 일치할 때만 연결하며 A.I. 변형이나 다른 무게에는 대신 적용하지 않습니다. C³는 기존 단면 비율을 사용하고 나머지 크기는 시각화용 가정값입니다. 공식 이미지 원본 링크를 각 모델 아래 제공합니다. 중지/약지 입구 테두리와 이름은 지공 전 예정 위치와 지공 후 모두 표시합니다. 기본 2홀 수치는 예시입니다. 홀 깊이·각도·코어 방향은 차트의 선택적 `simulation` 필드로 저장합니다. 기존 차트의 드릴경과 브리지는 3D에 연결되지만 inch 게이지 피치는 각도로 자동 변환하지 않습니다. 코어 기울기는 시각적 배치이며 PAP 레이아웃 해석기가 아닙니다.

카탈로그는 `sql/003-catalog.sql`을 적용한 Neon 테이블에 저장합니다. `catalog-sync` Netlify Scheduled Function은 매일 21:00 UTC(한국 오전 6시)에 브랜드 7개의 최신 목록을 조회하고, 브랜드별 최신 2개와 이전 출시 제품 2개를 신규/오래된 확인 순서로 갱신합니다. 이전 목록은 실제 페이지 링크에서 선택하고 12일마다 다음 페이지로 이동합니다. 초기 목록 확장은 `scripts/backfill-catalog.mjs`로 브랜드별 첫 2페이지를 동시 요청 4개 이내로 수집합니다. 중간 결과 JSON을 저장하고 재실행 시 확인한 제품을 건너뜁니다. 실패 시 기존 제품은 삭제하지 않으며 마지막 시도/성공 시간을 공개합니다. 소스는 bowwwl의 공개 제품 페이지이고 코어 이름·무게·출시일만 저장합니다. NEW는 출시일 이후 60일, 미래 날짜는 출시 예정, 날짜가 없으면 배지 없음입니다. 발견일이나 페이지 갱신일은 출시일로 사용하지 않습니다. 제품 정보 수집은 새 3D 형상 생성을 의미하지 않습니다.

수동 갱신: `node --env-file-if-exists=.env --experimental-strip-types scripts/sync-catalog.mjs`. 배포 전 `npm test`와 `npm run build`로 기존 권한/저장, 카탈로그 파서, 숫자 입력과 CSG 절삭을 확인합니다. 스케줄은 Netlify 프로덕션 배포에서만 실행됩니다.
